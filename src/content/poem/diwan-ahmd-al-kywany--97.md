من مجزوء

لَكَ الحَمدُ يا مَن حَصَل … لَنا لُطفَهُ وَاِتَصَل
بِمثل صَنيع الوَزير … يُحسن ضَرب المَثَل
سَميّ النَبيّ الَّذي … عَلى المُلك كانَ اِشتَمَل
وَفي مثل أَغداقِهِ … يَكادُ يَجور العَذل
دَعا الجَفلى لِدَعوَتِهِ … فَكادَ القَرى أَن يَمل
ختان جَرى بِالجدى … فَعَمَّ الوَرى بِالجَذل
لِشبلٍ لَهُ في السَنا … كَشَمس الضُحى في الحَمل
لِأَحمَدِ أَترابِه … بِتَفصيلِهِ وَالجَمَل
مُخَيلَتَهُ بَشَرت … بِمَجد لَهُ مُقتبل
وَقَد جاءَ تاريخُهُ … خِتان بِجود كَمل
فَكانَت لَهُ راعياً … عِناية مَن لَم يَزَل
إِذا عَمَّ عَدل الرُعا … ة صارَ الرَعايا خَول
وَيَنقاد لَيث الشَرى … إِلى حاكم إِن عَدَل
فَكَيفَ الَّذي جودَهُ … مَع العَدل أَيضاً شَمل
عَن البَحر سَلني أَجب … وَعَن صَدرِهِ لا تَسَل
فَما وَصفَهُ بِالَّذي … أَذا رُمتَ حَداً حَصَل
تَملك رق الوَرى … بِبشر يَروق المُقل
وَحُلم تَصفو العُلا … وَبِالعَدل تَبقى الدُوَل
أَرى الحُلم مثل الحَيا … يزان بِهِ مِن عَقل
وَما راقَ وَرد الخُدو … د إِلّا بِصَبغ الخَجَل
وَسَل عَنهُ يَوم الوَغى … مَواضي الظَبي وَالأَسَل
إِذا طارَ مِن خيفَةٍ … شُعاعاً فُؤاد البَطَل
ظَنَنت شبا سَيفِهِ … يُسابق وَشك الأَجَل
وَراحَ يَعدّ الجِرا … ح عِندَ اللُقا كَالقُبَل
فَكادَ يَموت الحَما … م مِن بَأسِهِ لِلوَجل
يَهنا عَدوٌّ رَأى … لَهُ راية فَاِنخَذَل
فَلا فاتَ راياتِهِ … بُلوغ المُنى وَالأَمَل
بِفَتح يَلي راحة … وَنَصر إِذا حَلَّ جَل
