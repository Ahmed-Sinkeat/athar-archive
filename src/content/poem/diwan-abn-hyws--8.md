من البحر الخفيف

كُن بَعيداً إِن شِئتَ أَو كُن قَريبا … فَأَياديكَ عِندَنا لَن تَغيبا
خَلفَكَ الآلاءُ مُذ سِرتَ فينا … فَتَساوَيتَ مَشهَداً وَمَغيبا
كَالغَمامِ الرُكامِ يَمضي وَيُبقي … مَورِداً فائِضاً وَمَرعىً خَصيبا
فُرقَةٌ يا أَبا العَلاءِ أَصارَت … حَسَناتِ الزَمانِ عِندي ذُنوبا
كَم سَبَقتَ الجارينَ في حَلبَةِ المَج … دِ وَكَلّوا وَما شَكَوتَ لُغوبا
لا كَما يَسبِقُ المُجاري المُجارى … بَل كَما يَسبِقُ الشَبابُ المَشيبا
لَم يَزَل جانِبي مَنيعاً مَهيباً … مُذ رَأَتني بِكَ الخُطوبُ مُهيبا
وَلِهَذا أَصبَحتُ مِن أَلَمِ الفُر … قَةِ أَوفى مُفارِقيكَ نَصيبا
وَلَوَ اِنّي مَلَكتُ نَفسي وَرَأيي … لَوَصَلتُ الإِسآدَ وَالتَأويبا
فَكَفاني مَؤونَةَ الشَوقِ عَزمٌ … لا يَمَلُّ التَقويضَ وَالتَطنيبا
غَيرَ أَنّي أُوَدِّعُ القَلبَ عِلماً … أَنَّهُ لا يَؤوبُ حَتّى تَؤوبا
