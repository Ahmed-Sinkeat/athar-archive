من البحر الوافر

طَرِبتَ وأَنتَ أَحياناً طَروبُ … وَكيفَ وَقَد تعَلّاكَ المَشيبُ
يُجِدّ النأَيُ ذِكرَكِ في فؤَادي … إِذا ذَهِلَت عَنِ النأي القُلوبُ
يؤَرِّقُني اكتِئابُ أَبي نُمَيرٍ … فَقَلبي مِن كآبَتِهِ كَئيبُ
فَقُلتُ لَهُ هَداكَ اللَهُ مَهلاً … وَخَيرُ القَولِ ذو اللُّبِّ المُصيبُ
عَسى الكَربُ الَّذي أَمسَيتُ فيهِ … يَكونُ وَراءَهُ فَرَجٌ قَريبُ
فَيأَمنَ خائِفٌ ويُفَكَّ عانٍ … وَيأَتي أَهلَهُ النائي الغَريبُ
أَلا لَيتَ الرياحَ مُسَخَّراتٌ … بِحاجَتِنا تُباكِرُ أَو تَؤوبُ
فَتُخبِرنا الشَمالُ إِذا أَتَتنا … وَتُخبِر أَهلَنا عَنّا الجَنُوبُ
فإِنّا قَد حَلَلنا دارَ بَلوى … فَتُخطِئُنا المَنايا أَو تُصِيبُ
فإِن يَكُ صَدرُ هَذا اليَومِ وَلّى … فإِنَّ غَداً لِناظِرِهِ قَريبُ
وَقَد عَلِمَت سُليَمى أَنَّ عودي … عَلى الحَدَثانِ ذو أَيدٍ صَليبُ
وأَنَّ خَليقَتي كَرَمٌ وأَنّي … إِذا أَبدَت نَواجِذَها الحروبُ
أُعينُ عَلى مَكارِمها وَأَغشى … مَكارِهَها إِذا كَعَّ الهَيوبُ
وأَنّي في العَظائِمِ ذو غَناءٍ … وأُدعى لِلفعالِ فأَستَجيبُ
وأَنّي لا يَخافُ الغَدرَ جاري … وَلا يَخشى غوائِلي الغَريبُ
وَكَم مِن صاحِبٍ قَد بانَ عنّي … رُميتُ بِفَقدِهِ وَهوَ الحَبيبُ
فَلَم أُبدِ الَّذي تَحنوا ضُلوعي … عَليهِ وإِنَّني لأَنا الكَئيبُ
مَخافَةَ أَن يَراني مُستَكيناً … عَدوٌ أَو يُساءَ بِهِ قَريبُ
وَيَشمَتَ كاشِحٌ وَيَظُنَّ أَنّي … جَزوعٌ عِندَ نائِبَةٍ تَنوبُ
فَبَعدَكَ سَدَّتِ الأَعداءُ طُرقاً … إِليَّ وَرابَني دَهرٌ يَريبُ
وأَنكَرتَ الزَمانَ وَكُلَّ أَهلي … وَهَرَّتني لِغيبِتكَ الكَليبُ
وَكُنتُ تُقَطَّعُ الأَبصارُ دوني … وإِن وَغِرَت مِنَ الغَيظِ القُلوبُ
وَقَد أَبقى الحَوادِثُ مِنكَ رُكناً … صَليباً ما تؤَيِّسُهُ الخُطوبُ
عَلى أَنَّ المَنيَّةَ قَد توافي … لِوَقتٍ والنوائِبُ قَد تَنوبُ
