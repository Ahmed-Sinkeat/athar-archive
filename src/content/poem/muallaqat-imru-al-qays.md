---
١ - قِفَا نَبْكِ مِنْ ذِكْرَى حَبِيبٍ ومَنْزِلِ … بِسِقْطِ اللِّوَى بَيْنَ الدَّخُول فَحَوْملِ

٢ - فَتُوْضِحَ فَالمِقْراةِ لمْ يَعْفُ رَسْمُها … لِمَا نَسَجَتْهَا مِنْ جَنُوبٍ وشَمْألِ

٣ - تَرَى بَعَرَ الأرْآمِ فِي عَرَصَاتِهَا … وَقِيْعَانِهَا كَأنَّهُ حَبُّ فُلْفُلِ

٤ - كَأنِّي غَدَاةَ البَيْنِ يَوْمَ تَحَمَّلُوا … لَدَى سَمُرَاتِ الحَيِّ نَاقِفُ حَنْظَلِ

٥ - وُقُوْفاً بِهَا صَحْبِي عَلَّي مَطِيَّهُمُ … يَقُوْلُوْنَ:لاَ تَهْلِكْ أَسَىً وَتَجَمَّلِ

٦ - وإِنَّ شِفائِي عَبْرَةٌ مُهْرَاقَةٌ … فَهَلْ عِنْدَ رَسْمٍ دَارِسٍ مِنْ مُعَوَّلِ؟

٧ - كَدَأْبِكَ مِنْ أُمِّ الحُوَيْرِثِ قَبْلَهَا … وَجَارَتِهَا أُمِّ الرَّبَابِ بِمَأْسَلِ

٨ - إِذَا قَامَتَا تَضَوَّعَ المِسْكُ مِنْهُمَا … نَسِيْمَ الصَّبَا جَاءَتْ بِرَيَّا القَرَنْفُلِ

٩ - فَفَاضَتْ دُمُوْعُ العَيْنِ مِنِّي صَبَابَةً … عَلَى النَّحْرِ حَتَّى بَلَّ دَمْعِي مِحْمَلِي

١٠ - ألاَ رُبَّ يَوْمٍ لَكَ مِنْهُنَّ صَالِحٍ … وَلاَ سِيَّمَا يَوْمٌ بِدَارَةِ جُلْجُلِ

١١ - ويَوْمَ عَقَرْتُ لِلْعَذَارَي مَطِيَّتِي … فَيَا عَجَباً مِنْ كورها المُتَحَمَّلِ

١٢ - فَظَلَّ العَذَارَى يَرْتَمِيْنَ بِلَحْمِهَا … وشَحْمٍ كَهُدَّابِ الدِّمَقْسِ المُفَتَّلِ

١٣ - ويَوْمَ دَخَلْتُ الخِدْرَ خِدْرَ عُنَيْزَةٍ … فَقَالَتْ:لَكَ الوَيْلاَتُ!،إنَّكَ مُرْجِلِي

١٤ - تَقُولُ وقَدْ مَالَ الغَبِيْطُ بِنَا مَعاً: … عَقَرْتَ بَعِيْرِي يَا امْرأَ القَيْسِ فَانْزِلِ

١٥ - فَقُلْتُ لَهَا:سِيْرِي وأَرْخِي زِمَامَه … ولاَ تُبْعدِيْنِي مِنْ جَنَاكِ المُعَلَّلِ

١٦ - فَمِثْلِكِ حُبْلَى قَدْ طَرَقْتُ ومُرْضِعٍ … فَأَلْهَيْتُهَا عَنْ ذِي تَمَائِمَ مُحْوِلِ

١٧ - إِذَا مَا بَكَى مِنْ خَلْفِهَا انْصَرَفَتْ لَهُ … بِشَقٍّ،وتَحْتِي شِقُّهَا لَمْ يُحَوَّلِ

١٨ - ويَوْماً عَلَى ظَهْرِ الكَثِيْبِ تَعَذَّرَتْ … عَلَيَّ، وَآلَتْ حَلْفَةً لم تَحَلَّلِ

١٩ - أفاطِمَ مَهْلاً بَعْضَ هَذَا التَّدَلُّلِ … وإِنْ كُنْتِ قَدْ أزمعْتِ صَرْمِي فَأَجْمِلِي

٢٠ - وَإنْ تكُ قد ساءتكِ مني خَليقَةٌ … فسُلّي ثيابي من ثيابِكِ تَنْسُلِ

٢١ - أغَرَّكِ مِنِّي أنَّ حُبَّكِ قَاتِلِي … وأنَّكِ مَهْمَا تَأْمُرِي القَلْبَ يَفْعَلِ؟

٢٢ - وَمَا ذَرَفَتْ عَيْنَاكِ إلاَّ لِتَضْرِبِي … بِسَهْمَيْكِ فِي أعْشَارِ قَلْبٍ مُقَتَّلِ

٢٣ - وبَيْضَةِ خِدْرٍ لاَ يُرَامُ خِبَاؤُهَا … تَمَتَّعْتُ مِنْ لَهْوٍ بِهَا غَيْرَ مُعْجَلِ

٢٤ - تَجَاوَزْتُ أحْرَاساً إِلَيْهَا وَمَعْشَراً … عَلَّي حِرَاصاً لَوْ يُسِرُّوْنَ مَقْتَلِي

٢٥ - إِذَا مَا الثُّرَيَّا فِي السَّمَاءِ تَعَرَّضَتْ … تَعَرُّضَ أَثْنَاءَ الوِشَاحِ المُفَصَّلِ

٢٦ - فَجِئْتُ وَقَدْ نَضَّتْ لِنَوْمٍ ثِيَابَهَا … لَدَى السِّتْرِ إلاَّ لِبْسَةَ المُتَفَضِّلِ

٢٧ - فَقَالتْ:يَمِيْنَ اللهِ، مَا لَكَ حِيْلَةٌ، … وَمَا إِنْ أَرَى عَنْكَ الغَوَايَةَ تَنْجَلِي

٢٨ - خَرَجْتُ بِهَا تمْشِي تَجُرُّ وَرَاءَنَا … عَلَى أَثَرَيْنا ذيل مِرْطٍ مُرَحَّلِ

٢٩ - فَلَمَّا أجَزْنَا سَاحَةَ الحَيِّ وانْتَحَى … بِنَا بَطْنُ خَبْتٍ ذِي حِقَافٍ عَقَنْقَلِ

٣٠ - هَصَرْتُ بِفَوْدَيْ رَأْسِهَا فَتَمَايَلَتْ … عَليَّ هَضِيْمَ الكَشْحِ رَيَّا المُخَلْخَلِ

٣١ - إذا التفتت نحوي تضوّع ريحُها … نسيمَ الصَّبا جاءت بريا القرنفُلِ

٣٢ - مُهَفْهَفَةٌ بَيْضَاءُ غَيْرُ مُفَاضَةٍ … تَرَائِبُهَا مَصْقُولَةٌ كَالسَّجَنْجَلِ

٣٣ - كَبِكْرِ المُقَانَاةِ البَيَاضَ بِصُفْرَةٍ … غَذَاهَا نَمِيْرُ المَاءِ غَيْرُ مُحَلَّلِ

٣٤ - تَصُدُّ وتُبْدِي عَنْ أسِيْلٍ وَتَتَّقي … بِنَاظِرَةٍ مِنْ وَحْشِ وَجْرَةَ مُطْفِلِ

٣٥ - وجِيْدٍ كَجِيْدِ الرِّيمِ لَيْسَ بِفَاحِشٍ … إِذَا هِيَ نَصَّتْهُ وَلاَ بِمُعَطَّلِ

٣٦ - وفَرْعٍ يَزِيْنُ المَتْنَ أسْوَدَ فَاحِمٍ … أثِيْثٍ كَقِنْوِ النَّخْلَةِ المُتَعَثْكِلِ

٣٧ - غَدَائِرُهُ مُسْتَشْزِرَاتٌ إلَى العُلا … تَضِلُّ العِقَاصُ فِي مُثَنَّى وَمُرْسَلِ

٣٨ - وكَشْحٍ لَطِيفٍ كَالجَدِيْلِ مُخَصَّرٍ … وسَاقٍ كَأُنْبُوبِ السَّقِيِّ المُذَلَّلِ

٣٩ - وَتُضْحِي فَتِيْتُ المِسْكِ فَوْقَ فِراشِهَا … نَؤُومُ الضَّحَى لَمْ تَنْتَطِقْ عَنْ تَفَضُّلِ

٤٠ - وتَعْطُو بِرَخْصٍ غَيْرَ شَشْنٍ كَأَنَّهُ … أَسَارِيْعُ ظَبْيٍ أَوْ مَسَاويْكُ إِسْحِلِ

٤١ - تُضِيءُ الظَّلامَ بِالعِشَاءِ كَأَنَّهَا … مَنَارَةُ مُمْسَى رَاهِبٍ مُتَبَتِّلِ

٤٢ - إِلَى مِثْلِهَا يَرْنُو الحَلِيْمُ صَبَابَةً … إِذَا مَا اسْبَكَرَّتْ بَيْنَ دِرْعٍ ومِجْوَلِ

٤٣ - تَسَلَّتْ عَمَايَاتُ الرِّجَالِ عَنْ الصِّبَا … ولَيْسَ فُؤَادِي عَنْ هَوَاكِ بِمُنْسَلِ

٤٤ - ألاَّ رُبَّ خَصْمٍ فِيْكِ أَلْوَى رَدَدْتُهُ … نَصِيْحٍ عَلَى تَعْذَالِهِ غَيْرِ مُؤْتَلِ

٤٥ - ولَيْلٍ كَمَوْجِ البَحْرِ أَرْخَى سُدُوْلَهُ … عَلَيَّ بِأَنْوَاعِ الهُمُوْمِ لِيَبْتَلِي

٤٦ - فَقُلْتُ لَهُ لَمَّا تَمَطَّى بِصُلْبِهِ … وأَرْدَفَ أَعْجَازاً وَنَاءَ بِكَلْكَلِ

٤٧ - ألاَ أَيُّهَا اللَّيْلُ الطَّوِيْلُ ألاَ انْجَلِي … بِصُبْحٍ، وَمَا الإصْبَاحُ منِكَ بِأَمْثَلِ

٤٨ - فَيَا لَكَ مَنْ لَيْلٍ كَأنَّ نُجُومَهُ … بكل مُغار الفتل شُدّت بيذبل

٤٩ - كَأَنَّ الثُرَيّا عُلِّقَت في مَصامِها … بِأَمْرَاسِ كَتَّانٍ إِلَى صُمِّ جَنْدَل ِ

٥٠ - وَقَدْ أغْتَدِي والطَّيْرُ فِي وُكُنَاتِهَا … بِمُنْجَرِدٍ قَيْدِ الأَوَابِدِ هَيْكَلِ

٥١ - مِكَرٍّ مِفَرٍّ مُقْبِلٍ مُدْبِرٍ مَعاً … كَجُلْمُوْدِ صَخْرٍ حَطَّهُ السَّيْلُ مِنْ عَلِ

٥٢ - كَمَيْتٍ يَزِلُّ اللَّبْدُ عَنْ حَالِ مَتْنِهِ … كَمَا زَلَّتِ الصَّفْوَاءُ بِالمُتَنَزَّلِ

٥٣ - مِسِحٍّ إِذَا مَا السَّابِحَاتُ عَلَى الوَنى … أَثَرْنَ الغُبَارَ بِالكَدِيْدِ المَرَكَّلِ

٥٤ - عَلَى الذبل جَيَّاشٍ كأنَّ اهْتِزَامَهُ … إِذَا جَاشَ فِيْهِ حَمْيُهُ غَلْيُ مِرْجَلِ

٥٥ - يزل الغُلاَمُ الخِفَّ عَنْ صَهَوَاتِهِ … وَيُلْوِي بِأَثْوَابِ العَنِيْفِ المُثَقَّلِ

٥٦ - دَرِيْرٍ كَخُذْرُوفِ الوَلِيْدِ أمَرَّهُ … تقلب كَفَّيْهِ بِخَيْطٍ مُوَصَّلِ

٥٧ - لَهُ أيْطَلا ظَبْيٍ، وَسَاقَا نَعَامَةٍ … وإِرْخَاءُ سَرْحَانٍ، وَتَقْرِيْبُ تَتْفُلِ

٥٨ - كَأَنَّ عَلَى الكتفين مِنْهُ إِذَا انْتَحَى … مَدَاكُ عَرُوسٍ أَوْ صَلايَةَ حَنْظَلِ

٥٩ - وبَاتَ عَلَيْهِ سَرْجُهُ ولِجَامُهُ … وَبَاتَ بِعَيْنِي قَائِماً غَيْرَ مُرْسَلِ

٦٠ - فَعَنَّ لَنَا سِرْبٌ كَأَنَّ نِعَاجَهُ … عَذَارَى دَوَارٍ فِي مُلاءٍ مُذيَل

٦١ - فَأَدْبَرْنَ كَالجِزْعِ المُفَصَّلِ بَيْنَهُ … بِجِيْدٍ مُعَمٍّ فِي العَشِيْرَةِ مُخْوِلِ

٦٢ - فَأَلْحَقَنَا بِالهَادِيَاتِ ودُوْنَهُ … جَوَاحِرُهَا فِي صَرَّةٍ لَمْ تُزَيَّلِ

٦٣ - فَعَادَى عِدَاءً بَيْنَ ثَوْرٍ ونَعْجَةٍ … دِرَاكاً، وَلَمْ يَنْضَحْ بِمَاءٍ فَيُغْسَلِ

٦٤ - وَظَلَّ طُهَاةُ اللَّحْمِ مِن بَيْنِ مُنْضِجٍ … صَفِيفَ شِوَاءٍ أَوْ قَدِيْرٍ مُعَجَّلِ

٦٥ - ورُحْنَا وَراحَ الطَّرْفُ ينفض رأسه … مَتَى تَرَقَّ العَيْنُ فِيْهِ تَسَفَّلِ

٦٦ - كَأَنَّ دِمَاءَ الهَادِيَاتِ بِنَحْرِهِ … عُصَارَةُ حِنَّاءٍ بِشَيْبٍ مُرَجَّلِ

٦٧ - وأنت إِذَا اسْتَدْبَرْتَهُ سَدَّ فَرْجَهُ … بِضَافٍ فُوَيْقَ الأَرْضِ لَيْسَ بِأَعْزَلِ

٦٨ - أحارِ تَرَى بَرْقاً أُرِيْكَ وَمِيْضَهُ … كَلَمْعِ اليَدَيْنِ فِي حَبِيٍّ مُكَلَّلِ

٦٩ - يُضِيءُ سَنَاهُ أَوْ مَصَابِيْحُ رَاهِبٍ … أَمان السَّلِيْطَ بالذُّبَالِ المُفَتَّلِ

٧٠ - قَعَدْتُ لَهُ وصُحْبَتِي بَيْنَ حامر … وبَيْنَ إكام، بُعْدَمَا مُتَأَمَّلِي

٧١ - فأَضْحَى يَسُحُّ المَاءَ عن كل فيقةٍ … يَكُبُّ عَلَى الأذْقَانِ دَوْحَ الكَنَهْبَلِ

٧٢ - وتَيْمَاءَ لَمْ يَتْرُكْ بِهَا جِذْعَ نَخْلَةٍ … وَلاَ أُطُماً إِلاَّ مَشِيداً بِجِنْدَلِ

٧٣ - كَأَنَّ ذُرَى رَأْسِ المُجَيْمِرِ غُدْوَةً … مِنَ السَّيْلِ وَالغُثّاءِ فَلْكَةُ مِغْزَلِ

٧٤ - كَأَنَّ أباناً فِي أفانين ودقه … كَبِيْرُ أُنَاسٍ فِي بِجَادٍ مُزَمَّلِ

٧٥ - وأَلْقَى بِصَحْرَاءِ الغَبيْطِ بَعَاعَهُ … نُزُوْلَ اليَمَانِي ذِي العِيَابِ المحملِ

٧٦ - كَأَنَّ سباعاً فِيْهِ غَرْقَى غُديّة … بِأَرْجَائِهِ القُصْوَى أَنَابِيْشُ عَنْصُلِ

٧٧ - عَلَى قَطَنٍ، بِالشَّيْمِ، أَيْمَنُ صَوْبِهِ … وَأَيْسَرُهُ عَلَى السِّتَارِ فَيَذْبُل

٧٨ - وَأَلْقى بِبَيسانَ مَعَ الليلِ بَرْكَهُ … فَأَنْزَلَ مِنْهُ العُصْمَ مِنْ كُلِّ مَنْزِلِ
