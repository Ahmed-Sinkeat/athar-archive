من البحر السريع

سَلام كَرَوض جاده وابل القطر … فَعطر أَرجاء المَحامد بِالنشر
سَلام بلا عَد وَلَو كُل لَوحة … جَرائد أَقلام تمد مِن البَحر
سَلام بلا عَد وَشَوق جَحيمه … يُؤجج ما بَينَ الجَوانح وَالصدر
سَلام بلا عَد وَشَوق بلا حَصر … يزف إِلى بَحر يَفوق عَلى البَحر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَعدن الأَفضال وَالوابل المثري
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن شَممنا مِنهُ رائِحة النَصر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن رَقا مَجداً عَلى الأَنجُم الزُهر
سَلام بلا عَد وَشَوق بلا حَصر … إلى مَن رَقا أَعلى المَناصب في الدَهر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن رَقا أَعلى المَراتب في البر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن رَقا أَعلى المَراتب في الفَخر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن رَقا أَعلى المَراتب في البَحر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن رَقا أَعلى المَحافل في العَصر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن رَقا أولى المَنازل في الذكر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مَن غَزَونا فيهِ طائِفَة الفقر
سَلام بلا عَد وَشَوق بلا حَصر … إِلى مشبع الأَضياف في اليسر وَالعسر
سَلام بلا عَد وَشَوق بلا حَصر … يَسير إِلى نعمان في ساعه اليُسر
سَلام بلا عَد وَشَوق إِذا سرت … نَسائمكم يَزداد بِالوَقد وَالحَر
سَلام بلا عَد وَلَو كُل كاتب … يُحاوله ضَبطاً لَما جاءَ بِالعشر
سَلام يُحاكي البَدر ضوءاً وَبَهجة … وَيزري نِظاماً بِالجَواهر وَالدر
