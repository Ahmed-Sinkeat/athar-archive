من البحر الطويل

رَسائل عَبد اللَه تحكي بِحُسنِها … مَحاسن حور العَين في جَنة الخُلد
رَسائل تروي عَنكُم أَطيب الثَنا … فَكانَت لَنا وَرداً وَناهيك مِن وَرد
رَسائل تروي الود عَنكُم مُسَلسلاً … صَحيحاً بِلا ضَعف سَليماً بِلا نَقد
رَسائل تروي الود عَن مُخلص الحشا … وَعَن طيب الأَعراق وَالأَب وَالجد
رَسائل تروي الرد عَن مُخلص الود … وَتَبعث أَشواقاً تَزيد عَلى العَد
رَسائل تروي الود عَن مُخلص الود … فَكانت كَبَدر التم في طالع السعد
رَسائل تروي الود عَن مُخلص الود … فَكانتَ كَماء المُزن سالَ بلا رَعد
رَسائل تروي الود عَن مُخلص الود … فَكانَت كَماء الوَرد أَو جرعة الشهد
رَسائل تروي الود عَن مُخلص الود … فَكانَت كَماء الوَرد يروي عَن الود
رَسائل تروي الود عَن مُخلص الود … فَكانَت كَماء الوَرد يروي عَن الوَرد
رَسائل تروي الود عَن مُخلص الود … فَكانَت كَماء الوَرد يروي عَن الرند
رَسائل تروي الود عَن مُخلص الود … فَكانَت كَماء الوَرد في حالة الوَرد
رَسائل تروي الود عَن مُخلص الود … فَكانَت كَماء الوَصل جاءَ بلا وَعد
رَسائل تروي الود عَن مُخلص الود … فَكانَت كَماء الحُسن في وَجنة الخَد
رَسائل تروي الود عَن مُخلص الود … وَمِن شَوقِهِ شَوقي وَمِن وجدِهِ وَجدي
رَسائل تروي الود عَن مُخلص الثَنا … وَمَن لَم يَزَل باق عَلى ذَلِكَ العَهد
رَسائل تروي الود عَن صاحب غَدا … قَريباً وَإِن طالَت بِنا شقة البُعد
رَسائل تروي عَن شَذا البان نَكهة … وَتَنشر مِن أَخباركم أَطيب الند
رَسائل تَحكي الروض مذ هبت الصبا … تُذَكرُنا سعدى وَتُخبر عَن نَجد
