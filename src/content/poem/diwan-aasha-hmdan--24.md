من البحر المتقارب

تَأَوَّبَ عَينُكَ عُوّارُها … وَعادَ لِنَفسِكَ تَذكارُها
وَإِحدى لَياليكَ راجَعتُها … أَرِقتَ وَنُوِّمَ سُمّارُها
وَما ذاقَت العَينُ طَعمَ الرُقا … دِ حَتّى تَبَلَّجَ إِسفارُها
وَقامَ نُعاةُ أَبي قاسِمٍ … فَأَسبَلَ بِالدَمعِ تَحدارُها
فَحَقُّ العُيونِ عَلى اِبنِ الأَشَج … جِ أَن لا يُفَتَّرُ تَقطارُها
وَأَلّا تَزالَ تُبَكّي لَهُ … وَتَبتَلَّ بِالدَمعِ أَشفارُها
عَلَيكَ مُحَمَّدُ لَمّا ثَوَي … تَ تَبكي البِلادُ وَأَشجارُها
وَما يَذكُرونَكَ إِلّا بَكَوا … إِذا ذِمَةٌ خانَها جارُها
وَعارِيَةٍ مِن لَيالي الشِتا … ءِ لا يَتَمَنَّحُ أَيسارُها
وَلا يَنبَحُ الكَلبُ فيها العَقو … رَ إِلّا الهَريرَ وَتَختارُها
وَلا يَنفَعُ الثَوبَ فيها الفَتى … وَلا رَبَّةَ الخِدرِ تَخدارُها
وَأَنتَ مُحَمَّدُ في مِثلِها … مُهينُ الجَزائِرِ نَحّارُها
تَظَلُّ جِفانُكَ مَوضوعَةً … تَسيلُ مِنَ الشَحمِ أَصبارُها
وَما في سِقائِكَ مُستَنطَقٌ … إِذا الشولُ رَوِّحَ أَغبارُها
فَيا واهِبَ الوُصَفاءِ الصَبا … حِ إِن شُبِّرَت ثَمَّ أَشبارُها
وَيا واهِبَ الجُردِ مِثلِ القِدا … حِ قَد يُعجِبُ الصَفَّ شُوّارُها
وَيا واهِبَ البَكَراتِ الهِجا … نِ عوذاً تَجاوَبُ أَبكارُها
وَكُنتَ كَدِجلَةَ إِذ تَرتَمي … فَيقذِفُ في البَحرِ تَيّارُها
وَكُنتَ جَليداً وَذا مِرَّةٍ … إِذا يُبتَغى مِنكَ إِمرارُها
وَكُنتَ إِذا بَلدَةٌ أَصفَقَت … وَآذَنَ بِالحَربِ جَبّارُها
بَعَثتَ عَلَيها ذَواكي العُيو … نِ حَتّى تَواصَلَ أَخبارُها
بِإِذنٍ مَنَ اللَهِ وَالخَيلُ قَد … أُعِدَّ لِذَلِكَ مِضمارُها
وَقَد تُطعَمُ الخَيلُ مِنكَ الوَجي … فَ حَتّى تُنَبَّذُ أَمهارُها
وَقَد تَعلَمُ البازِلُ العَيسَجو … رُ أَنَّكَ بِالخَبتِ حَسّارُها
فَيا أَسَفا يَومَ لا قَيتَهُم … وَخانَت رِجالَكَ فُرّارُها
وَأَقبَلَتِ الخَيلُ مَهزومَةً … عِثاراً تُضَرَّبُ أَدبارُها
بِشَطِّ حَروراءَ وَاِستَجمَعَت … عَلَيكَ المَوالي وَسَحّارُها
فَأَخطَرتَ نَفسَكَ مِن دونِهِم … فَحازَ الرَزيئَةَ إِخطارُها
فَلا تَبعَدَنَّ أَبا قاسِمٍ … فَقَد يَبلُغُ النَفسَ مِقدارُها
وَأَفنى الحَوادِثُ ساداتَنا … وَمَرُّ اللَيالي وَتَكرارُها
