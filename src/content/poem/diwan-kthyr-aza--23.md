من البحر الوافر

أَلَم يَحزُنكَ يومَ غَدَت حُدوجُ … لِعَزَّةَ إِذ أَجَدَّ بِها الخُروجُ
بِضاحي النَقبِ حينَ خَرَجنَ مِنهُ … وَخَلفَ مُتونِ ساقَتِها الخَليجُ
رَأَيتُ جِمالَها تَعلو الثَنايا … كَأَنَّ ذُرى هَوادِجِها البُروجُ
وَقَد مَرَّت عَلى تُرَبانَ تُحدى … لها بالنَعفِ مِن مَللٍ وَسيجُ
رَأَيتُ حُدوجَها فَظَلَلتُ صَبّا … تُهَيِّجُني مَعَ الحَزَنِ الحُدوجُ
إِذا بَصُرَت بِها العَينانِ لَجَّت … بِدَمعِهِما مَعَ النَظَرِ اللَجوجُ
وَبالسَرحاتِ مِن وَدّانَ راحَت … عَليها الرَقمُ كالبَلَقِ البَهيجُ
وَهاجَتني بَحَزمِ عُفارِيياتٍ … وَقَد يَهتاجُ ذو الطَرَبِ المُهيجُ
عَلى فُضُلِ الرَواعِ تَضَمَّنَتها … خَصِيباتُ المَعالِفِ وَالمُروجُ
يَشُجُّ بِها ذُؤابَةَ كُلِّ حَزنٍ … سَبوتٌ أَو مواكِبَةٌ دَروجُ
وَفي الأَحداجِ حينَ دَنونَ قَصراً … بِحزنِ سُوَيقَةٍ بَقَرٌ دُموجُ
حِسانُ السَيرِ لا مَتَوَاتِراتٌ … وَلا ميلٌ هَوادِجُها تَموجُ
فَكِدتُ وَقَد تَغَيَبَتِ التوالي … وَهُنَّ خواضِعُ الحَكَماتِ عوجُ
بِذي جَدَدٍ مِنَ الجَوزاء موفٍ … كَأَنَّ ضَبابَهُ القُطُنُ النَسيجُ
وَقَد جَاوَزنَ هَضبَ قُتائداتٍ … وَعَنَّ لَهُنَّ مِن رَكَكٍ شُروجُ
أَموتُ ضَمانَةً وَتَجَلَّلَتني … وَقَد أتهَمن مُردِمَةً ثَلوجُ
كَأَنَّ دُموعَ عَيني يَومَ بانَت … دَلاةٌ بَلَّها فَرَطٌ مَهيجُ
يُريعُ بِها غَداةَ الوِردِ ساقٍ … سَريحُ المَتحِ بكرَتُهُ مَريجُ
فَلَو أَبديتِ وُدَّكِ أُمَّ عَمروٍ … لَدى الإِخوانِ ساءَهُمُ الوَليجُ
لَكانَ لِحُبِّكِ المَكتومِ شَأنٌ … عَلى زَمَنٍ وَنَحنُ بِهِ نَعيجُ
تُؤَمّلُ أَن تُلاقيَ أُمَ عَمروٍ … بِمَكَّةَ حَيثُ يَجتَمِعُ الحَجيجُ
