من موشح

عَن التَأَنيب … وَيك عرج
ما نَهى الناهي … لي بمزعج
أَنا عَن حُبي … لَيسَ لي اِنتِقال
أَرضى في الحُب … أَن أَرى خَيال
كَئيب القَلب … أَرتجي مَنال
وَللكَئيب … حينَ يَرتَجي
باب الإِكراه … غَير مُرتج
غَزال ساحر … يَفتن البشر
ذوحسن باهر … قَيد البَصَر
أَوقَعت الناظر … مِنهُ إِذ نَظَر
عَلى تَرغيب … لَم يُبهرج
مِن خَد زاه … بِالتَضرج
عاطر يوجد … حامِداً هَواه
ثُنائي أَحمَد … ريحَهُ شَذاه
وَخَيلان الند … هُن مِن حَلاه
فَأَي طيب … مُتَأرج
يَغنى اللاهي … عَن بَنَفسج
أَراحَ الأَنسا … إِذا تَمَنعا
تَياه أَنسى … الصَبر مولعا
فَنادى النَفسا … وَالحَشا مَعا
يا نَفس ذوبي … يا حَشا اِبهجي
عَلى تياهِ … عَذب الشجى
قَلبي مِن جسمه … رَهن راحَتيهِ
لَكن مِن ظُلمه … أَشتَكي إَلَيه
وَأَدعو باسمه … مقسماً عَلَيه
أَحمد مَحبوبي … بِالنَبي يَتجى
