الاتصال العجيب بالتاريخ الميلادي 👇

قال الإمام الشافعي :

ولا يصلح بيع إلى عيد النصارى ( يعني موعد البيع يكون على تاريخ النصارى )
لأن الله تعالى حتم أن تكون المواقيت بالأهلة فيما وقته لأهل الإسلام

فقال تبارك وتعالى : { يسألونك عن الأهلة قل هي مواقيت للناس }
وقال تعالى { شهر رمضان الذي أنزل فيه القرآن }
وقال { الحج أشهر معلومات }
وقال : { ويسألونك عن الشهر الحرام }
وقال { واذكروا الله في أيام معدودات }

فأعلمَ اللهُ بالأهلة جمل المواقيت ، وبالأهلة مواقيت الأيام
ولم يجعل عَلَماً لأهل الإسلام إلا بها ...
