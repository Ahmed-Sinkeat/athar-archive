Book formatting: what changes, before → after

Every kind of change the formatting pass makes, using real passages from كتاب الإيمان لأبي عبيد, الأصول الثلاثة and التحفة السنية شرح منظومة ابن أبي داود الحائية (rules 11–15). The Before side is the reader today and the After side is the reader after the change. In the After panels, tap a green footnote number to see which note it opens. “Show markup” shows the raw file change. Anything marked your call has an alternative. Tell me if you want that one instead.

The one rule: only the markup changes: paragraphs, headings, footnote links. Not one letter, number or punctuation mark of the book changes. A script (format-verify) compares every edited book against the original and refuses the change if any text moved.

7 Numbered athar run together done: items 1–30 your call

Each numbered narration («٩- قال أبو عبيد…») was run into the one before it, often several in one paragraph. Each one now starts its own paragraph. The numbers stay as the book prints them, including the gap where 27 is missing.
Alternative: keep them together and only add space. I recommend separate paragraphs, because you can then highlight or share one narration.

10 Import errors: fixed and still open

Mistakes made by the import, not by the book. When the fix only moves text or renumbers a page, it is done in a separate step and checked by format-verify --import-fix: page numbers may change and text may move, but not one character may be added or lost. Text that is missing needs the original source, so it stays open.

Fixed

  • A page split in two at a new chapter. كتاب الإيمان had pages 35, 44, 49, 59, 62 and 67 twice each. The first marker goes, its notes join the second, and that page's later footnote numbers shift by one (page 67).
  • A page with the wrong number. التحفة السنية had pages 7, 11, 9, 10, 11; the first “11” is page 8.
  • Verses swapped across columns. See rule 15.

Still open: needs the original source

  • Lost text in كتاب الإيمان, p57→58. About three lines are missing, from فَأَيُّ شَيْءٍ يُتَّبَعُ بَعْدَ هَذِهِ الْحُجَجِ الْأَرْبَعِ؟ to ﴿إِلَّا إِبْلِيسَ اسْتَكْبَرَ…﴾ [ص:73-, so p58 starts with “74] ,”. The note on p57 even comments on words from the lost lines.
  • كتاب الإيمان stops early. It ends at p99. The other edition in the library (الإيمان للقاسم بن سلام - مخرجا) goes on with a final section, ذِكْرُ الْأَصْنَافِ الْخَمْسَةِ.
  • Hadith numbers eaten by the import. In التحفة السنية the old import cut every note at its “(number)” and threw the number away: أخرجه مسلم برقم ⟨…⟩ من حديث جابر. The pieces are joined again (rule 4), but the numbers are gone.
  • A footnote number that was never there. التحفة السنية p43 has a note (تقدم (ص 41)) but no number in the text. Adding one would add text.

Never changed

  • Any letter, number, punctuation mark or diacritic, even an obvious typo. Corrections are the editor's job, and his notes record them («الأصل: …»).
  • Note wording. Notes can be rejoined (rule 4), but never reworded or reordered.
  • Page markers. Never added, removed, moved or renumbered, except as a checked import fix (rule 10).
  • Book details (title, author, كتاب / متن type, topics).
  • New words. A heading can only be made from text already in the book.

The check script enforces all of this. If any text differs, it says where and refuses the change.
