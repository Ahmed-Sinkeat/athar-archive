## How the review was done (2026-10-26)

Each text was rendered exactly as the app parses it (blocks, headings, verse halves, footnotes). Texts marked **read in full** were read block by block; the rest had a structural scan of every block (verse pairing and numbering, heading breaks, paragraph walls, narration blocks, footnote links) plus a read of the flagged places. Checked: headings and their nesting, paragraphs, verse pairing, hadith/athar blocks and footnote links; every change passed `format-verify` (no letter, digit or punctuation changed). Wording was not compared against the printed editions.

Fixes applied across the set:

- Hadith collections and books built on narrations (`بلوغ المرام`، `المحرر`، `كتاب التوحيد`، `الأربعون النووية`، `مختصر الأذكار`): every narration wrapped whole, with its variant wordings and takhrij.
- Fiqh and nahw متون whose sentences were run together with single line breaks now have real paragraphs.
- 46 books across the library had verse lines written «صدر ... ... عجز», which the app showed as prose; the separator is now single so they render as verse.

Known limits:

- مختصر خليل has no punctuation in this edition; each fasl stays one long paragraph.
- Sentences cut by a page marker stay split as printed (the app shows the page divider there).
- The 14 missing texts above still need a source.

## Known limits found in the latest pass

- `mkhtsr-khlyl`: 60 paragraphs over 2,000 characters. Khalil's matn runs on without sentence punctuation, so clause breaks would be guesses. Left as is.
- `alfiyyah-al-suyuti`, `lamiyyat-al-afal`, `al-muharrar`: the source edition prints a `• • •` ornament at page ends. The gate counts it as text and removing it is rejected, so it stays visible.
- `hadya-awly-al-fhm-fy-nzm-hlya-talb-al-alm`, verse 64: a stray `_` around one word stops the hemistich split, so it shows as a single line. The underscore is in the source text; removing it is rejected by the gate.
- `shurut-al-salah`: a line that starts with `-` renders as a one-item list. Escaping it changes the text, so it stays.
- `al-aqeedah-al-saffariniyyah`, verse 100: the source has `ك ملحد` (a split word). Left as is.
- `al-aqyda-al-wastya-btalyq-abn-mana` and `lumat-al-itiqad`: Qur'an verses are in plain parentheses, not ornate brackets, so they get no verse styling.

## Scope decision (latest)

The user asked to skip the big books (the `book-lg` collection and the 100 KB+ poems). They stay at "audited / sampled" and are not being read in full for now. The small texts (everything in `book` and the short poems) went through block-by-block reading or the anomaly scan (unbalanced quotes and brackets, split words, stray verses, tiny fragments). The scan found nothing left to fix except the limits listed above.

Note on the scan: in the `book` collection a verse is stored as one block with the two hemistichs on two lines, so the "single-verse" flag is a false alarm there. In the `poem` collection it is real: `al-kwkb-al-zhry` (108) and `alfya-abn-malk` (77) have bayts written on one line with no separator.
