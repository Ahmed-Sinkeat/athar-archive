  headings, page markers, and metadata in the native reader.

- Five Room/cache tests passed on the same phone: transactional frame import, failed-import

Xiaomi rejected Gradle's streamed instrumentation install with
`INSTALL_FAILED_USER_RESTRICTED`. Installing the exact generated test APK with ADB's
`--no-streaming -t` path succeeded; `AndroidJUnitRunner` then reported `OK (5 tests)`.

M9 Media3 playback, or the M10 performance/accessibility matrix. Existing in-progress UI
styling edits were preserved and were not treated as an M5 acceptance gate.
